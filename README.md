# Employee Management System

The current working flow is a React/Vite employee directory backed by a Spring
Boot REST API and MySQL. The dashboard loads records from the API, supports
search and status filtering, and provides create, edit, and deactivate actions.
New employee codes are generated by department (`IT` -> `I0001`, `HR` ->
`H0001`, `Finance` -> `F0001`, `Sales` -> `S0001`, `Admin` -> `A0001`).

## Dependencies and restoration

### Backend

The backend uses Java 21, Spring Boot 4.1.2, Maven Wrapper 3.10.0, and
MySQL Connector/J 9.7.0. Dependencies declared in `backend/pom.xml` are:

- `spring-boot-starter-data-jpa` - JPA and database access
- `spring-boot-starter-validation` - request validation
- `spring-boot-starter-webmvc` - REST API and embedded server
- `mysql-connector-j` 9.7.0 - MySQL runtime driver
- `spring-boot-starter-data-jpa-test` - JPA testing support
- `spring-boot-starter-validation-test` - validation testing support
- `spring-boot-starter-webmvc-test` - web-layer testing support
- `h2` - in-memory database for tests
- `spring-boot-maven-plugin` - Spring Boot packaging and run support

Restore backend dependencies from the Maven Central repository with:

```powershell
cd backend
.\mvnw.cmd dependency:resolve
```

Run backend tests, which also resolves any missing test dependencies:

```powershell
.\mvnw.cmd test
```

The Maven wrapper uses the Maven version configured in
`backend/.mvn/wrapper/maven-wrapper.properties`; Maven does not need to be
installed globally.

### Frontend

The frontend uses React 19.3.1, React DOM 19.3.1, Vite 8.3.5, and
`lucide-react` 1.64.0. Packages declared in `frontend/package.json` are:

Runtime dependencies:

- `react` - UI library
- `react-dom` - React browser rendering
- `lucide-react` - interface icons

Development dependencies:

- `vite` and `@vitejs/plugin-react` - development server and production build
- `eslint`, `@eslint/js`, `eslint-plugin-react-hooks`, and
  `eslint-plugin-react-refresh` - linting
- `globals` - standard global variable definitions for ESLint
- `@types/react` and `@types/react-dom` - React type definitions

Restore the exact frontend dependency tree recorded in
`frontend/package-lock.json` with:

```powershell
cd frontend
npm ci
```

Use `npm install` instead when intentionally updating dependencies or when the
lockfile needs to be regenerated.

## Run locally

1. Create a MySQL database named `ems_db`. Set the database password through
   the `SPRING_DATASOURCE_PASSWORD` environment variable (and optionally set
   `MYSQL_USERNAME`; it defaults to `root`).
2. Install JDK 21 and set `JAVA_HOME`.
3. Start the API:

   ```powershell
   cd backend
   $env:SPRING_DATASOURCE_PASSWORD = "<your-mysql-password>"
   .\mvnw.cmd spring-boot:run
   ```

4. Start the frontend in another terminal:

   ```powershell
   cd frontend
   npm install
   npm run dev
   ```

The frontend uses `http://localhost:8080/api/employees`.

## Validation

```powershell
cd frontend
npm run build
npm run lint
```

Backend tests can be run with `.\mvnw.cmd test` from `backend` after Java 21
is installed.

## Current API

- `GET /api/employees`
- `GET /api/employees/{id}`
- `POST /api/employees`
- `PUT /api/employees/{id}`
- `DELETE /api/employees/{id}` (deactivates the employee)
