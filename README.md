# Employee Management System

The current working flow is a React/Vite employee directory backed by a Spring
Boot REST API and MySQL. The dashboard loads records from the API, supports
search and status filtering, and provides create, edit, and deactivate actions.
New employee codes are generated by department (`IT` -> `I0001`, `HR` ->
`H0001`, `Finance` -> `F0001`, `Sales` -> `S0001`, `Admin` -> `A0001`).

## Dependencies and restoration

### Backend

The backend uses Java 21, Spring Boot 4.1.2, Maven 3.10.0 through the Maven
Wrapper distribution, and MySQL Connector/J 9.7.0. The Maven Wrapper script
version is 3.3.4. The dependency versions below are the versions resolved from
Maven Central on 2026-10-29:

- `spring-boot-starter-data-jpa` 4.1.2 - JPA and database access
- `spring-boot-starter-validation` 4.1.2 - request validation
- `spring-boot-starter-webmvc` 4.1.2 - REST API and embedded server
- `mysql-connector-j` 9.7.0 - MySQL runtime driver
- `spring-boot-starter-data-jpa-test` 4.1.2 - JPA testing support
- `spring-boot-starter-validation-test` 4.1.2 - validation testing support
- `spring-boot-starter-webmvc-test` 4.1.2 - web-layer testing support
- `h2` 2.4.240 - in-memory database for tests
- `spring-boot-maven-plugin` 4.1.2 - Spring Boot packaging and run support

Spring Boot 4.1.2 and its dependency set are used with Java 21. MySQL
Connector/J is the only production database driver installed; PostgreSQL and
SQL Server drivers are not included.

Restore backend dependencies from the Maven Central repository with:

```powershell
cd backend
.\mvnw.cmd dependency:resolve
```

Run backend tests, which also resolves any missing test dependencies:

```powershell
.\mvnw.cmd test
```

The Maven wrapper uses the Maven 3.10.0 distribution configured in
`backend/.mvn/wrapper/maven-wrapper.properties`; Maven does not need to be
installed globally.

### Frontend

The frontend uses Node.js/npm, React 19.3.1, React DOM 19.3.1, and Vite 8.3.5.
The exact versions are locked in `frontend/package-lock.json`:

Runtime dependencies:

- `react` 19.3.1 - UI library
- `react-dom` 19.3.1 - React browser rendering
- `lucide-react` 1.64.0 - interface icons

Development dependencies:

- `vite` 8.3.5 and `@vitejs/plugin-react` 6.1.2 - development server and build
- `eslint` 10.13.0 and `@eslint/js` 10.0.1 - linting
- `eslint-plugin-react-hooks` 7.1.1 and `eslint-plugin-react-refresh` 0.5.7 - linting
- `globals` 17.13.0 - standard global definitions for ESLint
- `@types/react` 19.3.0 and `@types/react-dom` 19.3.0 - React type definitions

These frontend versions are compatible with the current Vite configuration and
React 19 application code. Node.js 20 or newer is recommended.

Restore the exact frontend dependency tree recorded in
`frontend/package-lock.json` with:

```powershell
cd frontend
npm ci
```

Use `npm install` instead when intentionally updating dependencies or when the
lockfile needs to be regenerated.

## Run locally

1. Create a MySQL database named `ems_db` and make sure the `MySQL80` service is
   installed. Install JDK 21 and Node.js 20 or newer.
2. Open two PowerShell terminals at the repository root.
3. In the first terminal, start the API:

   ```powershell
   .\run-backend.ps1
   ```

   The launcher detects Java 21, starts the `MySQL80` service when needed, and
   securely prompts for the MySQL root password. To avoid the prompt in a
   session, set `SPRING_DATASOURCE_PASSWORD` before running the command.
4. In the second terminal, start the frontend:

   ```powershell
   .\run-frontend.ps1
   ```

   The launcher installs the locked frontend dependencies automatically when
   `node_modules` is missing.

The frontend is available at `http://127.0.0.1:5174/` and uses
`http://localhost:8080/api/employees`.

## Validation

```powershell
cd frontend
npm run build
npm run lint
```

Backend tests can be run with `.\mvnw.cmd test` from `backend` after Java 21
is installed.

## Current API

- `GET /api/employees`
- `GET /api/employees/{id}`
- `POST /api/employees`
- `PUT /api/employees/{id}`
- `DELETE /api/employees/{id}` (deactivates the employee)
