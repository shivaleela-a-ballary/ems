# Employee Management System

The current working flow is a React/Vite employee directory backed by a Spring
Boot REST API and MySQL. The dashboard loads records from the API, supports
search and status filtering, and provides create, edit, and deactivate actions.
New employee codes are generated by department (`IT` -> `I0001`, `HR` ->
`H0001`, `Finance` -> `F0001`, `Sales` -> `S0001`, `Admin` -> `A0001`).

## Run locally

1. Create a MySQL database named `ems_db`. Set the database password through
   the `SPRING_DATASOURCE_PASSWORD` environment variable (and optionally set
   `MYSQL_USERNAME`; it defaults to `root`).
2. Install JDK 21 and set `JAVA_HOME`.
3. Start the API:

   ```powershell
   cd backend
   $env:SPRING_DATASOURCE_PASSWORD = "<your-mysql-password>"
   .\mvnw.cmd spring-boot:run
   ```

4. Start the frontend in another terminal:

   ```powershell
   cd frontend
   npm install
   npm run dev
   ```

The frontend uses `http://localhost:8080/api/employees`.

## Validation

```powershell
cd frontend
npm run build
npm run lint
```

Backend tests can be run with `.\mvnw.cmd test` from `backend` after Java 21
is installed.

## Current API

- `GET /api/employees`
- `GET /api/employees/{id}`
- `POST /api/employees`
- `PUT /api/employees/{id}`
- `DELETE /api/employees/{id}` (deactivates the employee)
